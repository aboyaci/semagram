# Examples

Each `.sem` file is one text, one sentence per line, `#` for comments, `# pack: name` to load a Layer 2 pack. Run `python3 -m semagram gloss <file>` for the gloss or `--tr` for Turkish.

- `fish-and-bird.sem` — an original five-page beginner story. The language's native genre; nearly every glyph is transparent and the repetition teaches the grammar as you read. Use this for cold-reader tests.
- `attention-abstract.sem` — the abstract of *Attention Is All You Need* (Vaswani et al., 2017) under v0.3 rules: 31 sentences for the original 7, every number and claim preserved, emphasis and framing lost. The stretch genre.

Both lint clean. The pre-rendered glosses are in `*.gloss.md`.
