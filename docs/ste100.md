# How much of ASD-STE100 does this cover?

ASD-STE100, Simplified Technical English, is the controlled language the aerospace industry uses for maintenance documentation. It is the closest thing in production use to what this project is: a deliberately small, rule-bound subset built so that non-native readers get one unambiguous reading. It has two halves: about 65 **writing rules** and a **dictionary** of roughly 900 approved general words, each with exactly one approved meaning and part of speech, plus an open allowance for *technical names* and *technical verbs* that a company defines for itself.

Short answer: **most of the rules, little of the dictionary, and the dictionary gap is smaller than it looks because STE's own escape hatch is our Layer 2.**

The STE specification is free but copyrighted, and the approved word list is not reproduced here. The rule-by-rule comparison below is from the published structure of the standard; the vocabulary estimate is against the categories of words it approves, not a word-by-word count. Treat the percentages as a reading, not a measurement.

## The writing rules

STE's rules exist because English permits things a reader can misread. Most of them describe a language we already have, because the misreadable construction does not exist here.

| STE rule (paraphrased) | Here | Status |
|---|---|---|
| One approved meaning per word, one part of speech | Each glyph has one gloss; parts of speech do not exist, position decides | **Built in** |
| No -ing forms (gerunds, present participles) | No inflection exists. The abstraction is a determinative: `🧠📈📜` learning | **Built in** |
| Only approved verb forms (imperative, simple past, simple present, future, past participle as adjective) | Three tenses, no aspect, no mood. There is nothing else to use | **Built in** |
| Active voice; passive only where the agent is unknown | Passive does not exist. The agent slot is filled or left empty | **Built in** |
| Noun clusters of at most three words | The 3-root cap per word | **Built in** |
| Procedural sentences ≤ 20 words, descriptive ≤ 25 | Average sentence is 3 words; the linter caps arguments at three | **Exceeded** |
| One instruction per sentence | Pidgin chaining; no embedding exists | **Built in** |
| Start a safety instruction with a clear command | Predicate-first: every sentence starts with the command | **Built in** |
| Use `if` and `when` for conditions, never ambiguous phrasing | 🔺 *if* opens the condition sentence; 🕐 *when*. Both explicit | **Covered** |
| Write one topic per paragraph; use vertical lists for steps | One sentence per line is already house style; numerals pass through | **Covered** |
| Use articles (the, a) to mark nouns | No articles. Nouns are marked by not being first | **Not applicable** |
| Approved technical names and verbs may be used | 🏷️ cartouche and `≔` domain packs | **Covered** |
| Warnings and cautions precede the step they protect | No convention yet | **Gap** |
| Commands (imperatives) are the default procedural mood | No mood marker | **Gap, trivial** |

By count, roughly two thirds of STE's rules are either satisfied automatically or made meaningless by the grammar. That is not a coincidence: STE and this project are both trying to remove the same ambiguities from the same kind of text.

The two gaps have obvious fills, offered here as **proposals, not rules**, because the standing policy is that nothing is legislated until a real sentence breaks:

- **Imperative = predicate with an empty agent slot**, exactly as in English. `🔓🚪🔷` *open the door*. With an agent it is a statement: `🔓🙋🚪🔷` *I open the door*. This is already how the glosser renders it; it just has no name.
- **⚠️ as an opener** for *warning* / *caution*, placed in the sentence before the step, matching STE's ordering. The glyph is transparent on every platform.

## The dictionary

STE's ~900 words fall into categories. Against each:

| STE category | Example words | Coverage here |
|---|---|---|
| Logical and functional words (not, if, when, because, and, or, more, less, all, some) | | **Full.** This is Layer 0 |
| General verbs of action (make, do, use, move, open, close, cut, put, remove, install, connect, start, stop, turn, hold, apply, clean, test, measure) | | **About half.** 🔨 🤜 🔧 🏃 🔓 🔒 ✂️ 🐣 🏁 🧪 ⚖️🧮 exist; *remove, install, connect, turn, hold, clean, apply* do not |
| Quantity, dimension, position (above, below, inside, near, far, large, small, number, part, side) | | **Full** |
| Time (before, after, now, day) | | **Full** |
| Physical nouns of the general kind (water, air, fire, light, sound, stone, machine, tool, computer) | | **Mostly.** Missing: *surface, hole, line, wire, box, cover* |
| Evaluation (good, bad, correct, safe, dangerous, necessary) | | **Partial.** 👍 👎 ✅ ❌ exist; *safe, dangerous, necessary* do not |
| Mental and communication (know, think, see, show, tell, read, write) | | **Full** |
| Procedure structure (step, procedure, sequence, condition, result, task) | | **Weak.** *task* and *result* are already the top two Layer 1 candidates from the abstract translation; *step* and *sequence* join them |
| Aerospace technical names (actuator, bolt, torque, hydraulic…) | | **Not applicable.** STE itself exempts these; they are a domain pack |

Head-on, our ~150 dictionary items cover perhaps **15–20%** of STE's 900 by count. But STE's 900 includes several hundred words that exist only because English needs them (articles, auxiliaries, prepositions, synonyms STE had to pick between). Measured as **concepts a maintenance procedure needs**, coverage is nearer **40%**, and the missing 60% is almost entirely concrete nouns and action verbs, the cheap kind of word: transparent pictures (🔩 🔌 🧹) that pass Test B on sight. The hard words, the logical and functional skeleton that took most of this project's effort, are already there.

## Where the comparison stops

Two things STE has that this project cannot have:

1. **A speech form.** STE is English; a mechanic can read a step aloud. This language has no sound, which is also why no rebus/phonetic exit from the picture wall exists (see [history.md](history.md) §10).
2. **Fifty years of corpus.** STE's word list was pruned against real manuals. Ours has been tested against one abstract and one picture book. The vocabulary half of this comparison will only be meaningful after a real procedure has been translated.

## A worked fragment

An original, generic three-step procedure in STE style, and what it exposes:

| STE English | Here | Gloss |
|---|---|---|
| Open the cover. | `🔓🔒👉🔷` | open(cover-this) — *cover* has no root; 🔒 (close/lid) is a stretch |
| CAUTION: Do not touch the terminals. | `⚠️🔷` `📏🌑❌🫵🔌🔷` | warning · touching-not(you, connector) — needs ⚠️ and a *connector* root |
| Disconnect the connector. | `🔗❌🔌🔷` | join-not(connector) — ❌ on a verb gives the honest *un-join*; STE would call this *disconnect* |
| Measure the voltage. | `⚖️🧮⚡🔷` | measure(electricity) — *voltage* is a technical name; a pack would declare `⚡🪜` ≔ voltage |
| If the value is more than 28 V, replace the unit. | `🔺📈👉28🔷` `🦋🫵⚙️🔷` | if more(this, 28) · change(you, machine) — *replace* came out as *change*; adequate |

Five sentences, three new words needed (*cover, connector, warning*), one convention (⚠️). That is the rate the abstract produced too: the language is one short domain pack away from a maintenance procedure, and the pack is the easy part.

## Verdict

Rules: about two thirds covered, two trivial additions to reach near-full. Dictionary: a fifth by word count, two fifths by concept, with the hard fifth done and the easy three fifths not yet started. The honest test is to take one real STE-conformant procedure (any public aircraft maintenance manual page will do) and translate it with the linter running; every lint error and every `?` in the gloss is a dictionary entry with evidence behind it.
